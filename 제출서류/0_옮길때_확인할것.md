- [ ] 팀명 채우기. 개인 참가로 바꾸려면 문서 1의 분류 표시도 함께 바꾼다
- [ ] QR 이미지 2개 삽입 (웹, Android 설치)
- [x] 구현 이미지 6장. `화면/` 폴더에 있다. 2026년 7월 30일 최신 빌드(0.2.3) 실기기 캡처다
- [ ] 기획서 10페이지 이내 확인 (표와 이미지 크기 조절)
- [ ] 문서 4의 동의 표시는 담당자 확인 뒤에 한다
- [ ] 서비스에 적용한 정책 문안 3종의 법적 검토 결과 반영
- [ ] 참가신청서와 기획서의 작품명이 서로 같은지 확인
