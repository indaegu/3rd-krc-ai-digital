# design-system.md — 디자인 시스템

> UI 작업 전에 읽는다. **이 문서가 시각 토큰·컴포넌트 규칙의 SSOT**다.
> `prototype/mulsigye-app-prototype-v2.html`은 인터랙티브 참고물이며 충돌하면 이 문서를 따른 뒤
> 같은 작업에서 프로토타입을 갱신한다. 제품 행동·수치 의미는 [product.md](product.md)가 우선한다.

## 방향

흰 배경, 단색 카드, 큰 볼드 타이포, 넉넉한 여백, 짧은 ~해요체를 사용한다.
고령 농업인이 햇빛 아래 휴대전화에서 읽고 누를 수 있는지를 우선한다.

## 토큰

```css
--ink:#191F28; --ink2:#4E5968; --ink3:#8B95A1; --ink4:#B0B8C1;
--bg:#FFFFFF; --gray50:#F9FAFB; --gray100:#F2F4F6; --gray200:#E5E8EB;
--blue:#2D83FF; --blue-deep:#1F6FE6; --blue-tint:#E8F3FF; --blue-soft:#D6E8FF;
/* 브랜드 그라디언트(스플래시·온보딩·메인 헤더 배경): 시안→연블루→오프화이트 */
--grad-top:#A6EEF9; --grad-mid:#C1E8FF; --grad-bottom:#F6F6F6;
/* 공식 가뭄 단계 fg/bg */
--ok-fg:#00986F;    --ok-bg:#E6F6F0;
--watch-fg:#9A6700; --watch-bg:#FFF3D6;
--care-fg:#D9510C;  --care-bg:#FFEBDE;
--alert-fg:#E5372F; --alert-bg:#FDEBEA;
--crit-fg:#A11C1C;  --crit-bg:#F8E2E2;
--r-lg:24px; --r-md:18px; --r-sm:12px; --r-card:12px; /* 카드=12, 바텀시트=24 */
```

- 색·radius·폰트의 근거는 Figma 디자인 시안(fileKey iBWqexj5tpQX5aNilBnRoY)이다. 값은 시안에서만 온다.
- 웹은 전역 CSS 변수, Android는 의미가 같은 Compose `ColorScheme`·shape 토큰으로 옮긴다.
- 이름을 번역 구현하더라도 `ok/watch/care/alert/crit` 의미와 값은 바꾸지 않는다.
- **Pretendard를 self-host한다**(웹: next/font local `PretendardVariable.woff2`; Android: `res/font`
  정적 4굵기 + `MulsigyeTypography` `fontFamily`). 명조·원격 CDN 폰트는 쓰지 않는다.
- 메인 모듈 카드 radius는 12dp(`--r-card`), 필수 바텀시트는 24dp(`--r-lg`)로 구분한다.
- 공식 단계 임계값은 색 문서가 아니라 `apps/web/src/lib/data/drought-stage.ts`에만 둔다.

## 레이아웃·컴포넌트

- 메인 모듈 간격 24px. 카드 `--gray50`, radius 24px, 내부 패딩 20px.
- 주 CTA 높이 60px, **완전한 pill**(radius 999px/CircleShape), `--blue`, 글자 굵기 700. 비활성은 `--gray200`.
- 비이커는 지역 평년 대비 저수율(`avgRatio`)을 물 높이로 보여주고, **물 색은 파랑(`--blue`)
  으로 고정한다**(시안). 단계는 색으로 구분하지 않고 수위 위치 + 비이커 우측 세로 스케일
  (위→아래 정상/관심/주의/경계/심각) + 경계 눈금선(70/60/50/40)으로만 전달한다(접근성 규칙).
  **임계값·라벨 위치는 서버 `stageBands`에서만 오며 클라이언트에 복제하지 않는다**(규칙 10).
  값이 없으면 눈금·스케일 없이 채움만 그린다.
- 메인 게이지 카드는 좌상단 탭 라벨에 **대표 저수지명**(서버값)을 얹고, 그 아래
  **“평년 대비 {단계}”**(단계는 fg 색 텍스트, 알약 대신 인라인 — 시안 §4) + 큰 값
  (`avgRatio`, 52px)으로 쓰며, 대표 저수지 원저수율은 **“저수지 실제 저수율은 …%예요”**
  작은 보조 줄로 분리한다. 색만으로 단계를 구분하지 않도록 단계명을 텍스트로 함께 쓴다.
- 단계 칩(StageChip)은 상세(`/trend`)의 **단계 기준 안내** 등에서 단색 tint로 쓴다
  (메인 게이지 카드는 위 인라인 텍스트를 쓰므로 칩을 얹지 않는다).
- 그래프 제목·축·대체 텍스트에는 **“지역 평년 대비 저수율”**을 명시한다. x축 날짜는 7일 간격
  눈금 + ‘오늘’로 두고, 라벨이 겹치지 않게 끝·‘오늘’ 주변 눈금은 솎아낸다.
- 단계 뱃지와 만수위 참고 배너를 같은 위험 체계처럼 보이게 합치지 않는다.
- 바텀시트는 상단 radius 24px, 그랩바, `rgba(25,31,40,.45)` 딤을 쓴다. 필수 동의 시트는
  더 진한 딤과 뒤 콘텐츠 blur로 뒤 화면을 읽을 수 없게 한다(구형 OS는 딤만).
- 지역 목록 관리 모드: 줄을 길게 눌러 들어간다(스크린리더는 줄의 “지역 관리” 커스텀 액션).
  드래그는 “위로/아래로 이동” 커스텀 액션으로 접근성 대체를 제공한다. **일반 모드 상단에는
  액션 버튼을 두지 않고**(알림 설정은 앱 환경설정에 있다), 관리 모드에서만 선택 삭제·완료
  아이콘을 보여준다.
- 등록된 지역이 없으면 빈 상태 안내 카드를 두지 않는다 — 상단 안내 문구와 “지역 추가하기”만 둔다.
- “기본 주소지” 배지는 선택된 행(`--blue-tint`)과 구분되도록 **흰 배경 + 파란 글자**로 둔다.
- 지역 목록 한 줄은 **하나의 카드**다(radius 12, 일반 60dp/관리 68dp). 이름 오른쪽에 작은
  “기본 주소지” 배지, 삭제 X·드래그 손잡이도 같은 카드 안에 두고 터치 영역만 48dp로 분리한다.
- 주소 입력창은 초점과 무관하게 `--blue` 2px 테두리 + radius 18px이며, 안에는 입력 예시
  플레이스홀더를 둔다(떠오르는 라벨 대신 접근성 이름을 준다).
- 메인 배경은 온보딩·스플래시와 같은 브랜드 그라디언트를 화면 전체에 깐다(카드가 그 위에 얹힌다).
- 메인 헤더 우상단 pill: **알림 모아보기(Android만) · 앱 환경설정**. 새로고침은 헤더 아래
  기준시각 탭(48dp)과 당겨서 새로고침이 담당한다.
- 주변 지역 비교는 도 안 지역이 많으면 우리 지역 중심 5곳만 먼저 보이고 “N곳 더 보기”로
  펼친다(카드 안에 별도 스크롤을 만들지 않는다).
- 온보딩 페이지 점은 현재=`--blue`(가로로 긴 알약), 나머지=`--ink4`(그라디언트 배경에서
  `--gray200`은 보이지 않는다).

- 화면 제목은 Android `titleLarge` 20sp, 웹 1.2~1.35rem 급으로 둔다(고령 가독성은 본문 크기로 지킨다).

## 로딩 패턴

| 상황 | 패턴 |
|---|---|
| 메인 진입·새로고침 | 모듈별 스켈레톤(TDS식 pulse 0.9s 호흡, reduced-motion 정적); 풀스크린 스피너 금지 |
| 주소 검색 | 결과 영역 인라인 스피너 |
| 등록·삭제 버튼 | 버튼 내부 흰 스피너 + 중복 입력 잠금 |
| 헤더 기준 시각 | “불러오는 중…” 텍스트 |

## 애니메이션

- 물 출렁임: 회전 타원 2겹(7s / 11s reverse), 수위 0→목표 1.6s.
- 스플래시·전환 화면: 태그라인 페이드+8px 상승, 로고 스케일 0.86→1 등장 후 전체 페이드아웃.
  로고 회전 금지. “시작하기”로 메인에 들어갈 때마다 이 전환을 재생한다.
- 화면 전환: fade + 7% 슬라이드, 0.3s.
- 저수율 흐름 그래프: 첫 표시에 선·밴드가 좌→우로 그려지는 draw-in(~0.82s). 상세 그래프는
  가로축에 날짜(첫날·오늘·마지막)를 표시하고, 예측선이 평평한 뜻을 보조 문구로 안내한다.
- 웹 `prefers-reduced-motion`과 Android 시스템 “애니메이션 삭제” 설정에서 장식 모션을 끈다.
- 새 애니메이션은 두 플랫폼의 reduced-motion 처리와 함께 추가한다.

## 접근성

- 본문 15px 이상, 핵심 숫자 3rem급, 텍스트 대비 WCAG AA 이상.
- 터치 목표 최소 48×48dp, 아이콘 단독 버튼에는 접근 가능한 이름을 제공한다.
- 웹은 `:focus-visible` 아웃라인, 의미 있는 heading 순서, 라이브 영역 남용 금지.
- Android는 TalkBack 읽기 순서·contentDescription·큰 글꼴 1.3배에서 레이아웃을 확인한다.
- 색만으로 단계를 구분하지 않고 단계명과 기준을 텍스트로 쓴다.

## 콘텐츠 가드

- “가까운 저수지”, 거리, 로그인 CTA를 만들지 않는다.
- 알림은 **명시적 옵트인 설정**만 허용한다(Android 전용, 기본 꺼짐). 진입은 중립적으로만 둔다:
  지역 설정 화면의 “알림 설정” 아이콘, 앱 환경설정의 “알림 설정” 행, 그리고 메인 헤더의
  **“알림 모아보기”**(이미 받은 알림을 다시 보는 곳). 켜라고 부추기는 유도(다크패턴) 문구·배너·
  상시 배지·도트는 만들지 않는다. 웹에는 알림 UI가 전혀 없다(apps/web/AGENTS.md).
- 예측은 “가능성이 있어요” 형식만 사용하고 공식 예·경보 우선 문구를 함께 둔다.
- 오류는 원인을 쉬운 말로 설명하고 재시도 가능할 때만 재시도 버튼을 표시한다.

## 갱신 규칙

토큰·컴포넌트·플랫폼 매핑을 바꾸면 웹 CSS, Compose Theme, 프로토타입을 같은 변경에서 맞춘다.
프로토타입에서 먼저 실험했더라도 승인된 결과를 이 문서에 반영해야 제품 규칙이 된다.
